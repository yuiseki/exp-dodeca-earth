# fab6

注意: このフォルダのファイルは rev E (草案、2026-11-07 に出力、未発注)。発注した rev D (辺まで 26 mm、結束バンド用の長穴 10 個、ソケットは手はんだ) のファイルは、コミット e105b53 の `hardware/hub6_one/fab6/` にある。rev E は、Sense の拡張基板 (素の XIAO より約 4.3 mm、カメラつきで約 9.5 mm 高い) を載せたお椀が閉まるように、基板をお椀の奥へ約 7.2 mm 沈め (壁が深さ 1 mm ごとに 0.5 mm 狭まるので、辺 1 mm 減で 2 mm 沈む)、ソケットを 8.5 mm から 5.0 mm にした版。基板は作ったあとで左右反転しており、XIAO は上面 (F) のソケットに挿す。JLCPCB の組み立ては片面だけなので、U1 と C2、C3 も上面の、ソケットの間 (XIAO の下) に置いた。XIAO の A0〜A2 のピンと、画面ごとのアドレスは rev D と違う (ファームは `-DHUB6_ONE_REV_E` でビルドする)。

hub6_one の、JLCPCB にアップロードするファイル。`/usr/bin/python3 fab.py` が `build/fab/` に作り、ここへ写す。

- `hub6_one-gerbers.zip`: ガーバーとドリル (2 層、辺まで 22.4 mm の正五角形の外形、長穴なし)
- `hub6_one-bom.csv`: 部品表 (LCSC の部品番号つき。J7、J8 ソケット HC-PM254-5.0H-1x7PZ C27985232 (挿入部品)、U1 74HC138 C2674688、C2 10uF C15850、C3 100nF C14663。どれも上面。ソケット以外は cubic-earth の hub3 と同じ部品)
- `hub6_one-cpl.csv`: 部品の配置 (上面のみ)

載らないもの (手で付ける):

- ケーブル用の穴 (J1〜J6。rev E の側面の列は 2.8 mm おき): ケーブルを手ではんだ付けする。底面の J6 (2 列 x 4) は rev E からジグザグの番号 (上の列に奇数、下の列に偶数、1 VCC と 8 BL が反対の角) で、ケーブルの線をその順のまま差せる。rev D は DIP-8 の番号で、ケーブルの両端の VCC と BL が隣り合い、線がねじれた
- XIAO ESP32-S3 本体: ソケットに手で挿す (XIAO 側のピンヘッダーは XIAO に付属のもの)。ソケットは本体 5.0 mm で、ピンを受ける接点は上から 3 mm。XIAO のオスピンが 6 mm あるときは、底に当たって XIAO が浮かないよう、4 mm ほどに切る (未確認)

発注の前に確かめること:

- 見積もりの PCB の仕様: 表面処理は鉛フリー HASL にする。OSP だと経済 PCBA が選べず、標準 PCBA (設定料金とステンシルで約 $34 増し) に回される (2026-11-07。経済 PCBA の色と表面処理の組み合わせは https://jlcpcb.com/jp/capabilities/pcb-assembly-capabilities )

- 部品配置の確認画面で、U1 の向き (1 番ピンの印の位置)。SOIC-16 の JLCPCB 上の向きは、cubic-earth の hub3 で確かめた補正 (`fab.py` の `JLC_ROTATION_OFFSET`、-90 度) を使っているが、この基板では未確認
- U1 (C2674688) の在庫と値段。手元の部品の DB は 7 月の版
- 部品配置の確認画面で、ソケット J7、J8 (挿入部品) が基板の穴に合っているか、U1 の向き (1 番ピンの印。rev D とは 180 度違う向きに置いている)
- 挿入部品 (ソケット) を、表面実装と同じ面で受けてもらえるか (見積もりの画面で)
