# hub6_bench

hub6 の基板を発注する前に、XIAO ESP32-S3 1 枚と 74HC138 で、1.28 インチ丸型 LCD (GC9A01、Waveshare 1.28inch LCD Module) 6 枚を本当に駆動できるかを、ブレッドボードで確かめるスケッチ。ピンの割り当ては hub6 の基板 (`hardware/hub6/README.md`) と同じ。

## ビルドと書き込み

```sh
arduino-cli compile --fqbn esp32:esp32:XIAO_ESP32S3 --output-dir build .
arduino-cli upload --fqbn esp32:esp32:XIAO_ESP32S3 --input-dir build -p /dev/ttyACM0   # ポートは arduino-cli board list で
```

ライブラリは M5GFX (0.2.32 で確認。中の LovyanGFX の `Panel_GC9A01` を使う)。ESP32 の Arduino core は 3.3.12 で確認。

## 配線

電源はすべて XIAO の 3V3 から取る (ディスプレイの VCC は 3.3V。理由は hub6 の README)。XIAO の 5V は使わない。

### XIAO と 74HC138 (TC74HC138AP などの DIP-16)

| XIAO | 74HC138 | 意味 |
|---|---|---|
| D7 | 1 (A) | A0 |
| D8 | 2 (B) | A1 |
| D9 | 3 (C) | A2 |
| GND | 4 (G2A)、5 (G2B)、8 (GND) | 常に有効 |
| 3V3 | 6 (G1)、16 (VCC) | 常に有効、電源 |

74HC138 の 16 番と 8 番の間に、0.1uF のコンデンサを 1 個入れる (基板の C3 と同じ)。

### ディスプレイ (付属の PH2.0 と Dupont のケーブル)

6 枚とも同じ線を共有する。ブレッドボードで、信号ごとに 1 列を作り、XIAO と 6 枚をその列につなぐ。

| ディスプレイの線 | 付属ケーブルの色 | つなぐ先 |
|---|---|---|
| VCC | 紫 | XIAO 3V3 |
| GND | 白 | XIAO GND |
| DIN | 緑 | XIAO D0 |
| CLK | オレンジ | XIAO D1 |
| CS | 黄 | 74HC138 の出力 (下の表) |
| DC | 青 | XIAO D3 |
| RST | 茶 | XIAO D4 |
| BL | 灰 | XIAO D5 |

色は、ディスプレイに付属の PH2.0 と Dupont のケーブルのもの (2026-10-21 に実物で確かめた)。hub6 の基板に使う「PH2.0 とより線」のケーブル (Amazon) の色は、これと同じとは限らない。

| ディスプレイ | CS をつなぐ 74HC138 のピン | アドレス |
|---|---|---|
| P1 | 15 (Y0) | 0 |
| P2 | 14 (Y1) | 1 |
| P3 | 13 (Y2) | 2 |
| P4 | 12 (Y3) | 3 |
| P5 | 10 (Y5) | 5 |
| BASE | 11 (Y4) | 4 |

P5 と BASE が入れ替わって見えるのは、基板の配線の都合 (hub6 の README の表と同じ)。74HC138 の 9 番 (Y6) と 7 番 (Y7) は何にもつながない。

XIAO の D2、D6、D10 は使わない。

## 動き

1. 電源を入れると、6 枚を 1 回だけリセットし、1 枚ずつ初期化する
2. 3 秒間、各ディスプレイが自分の名前、アドレス、色を表示する (P1 赤、P2 緑、P3 青、P4 黄、P5 マゼンタ、BASE シアン)
3. そのあと、6 枚を順に全面塗りつぶす試験を続ける。自分の色と黒が交互に入れ替わり、真ん中に名前が出る。シリアル (115200) に、2 秒ごとに「1 秒に何回、6 枚ぶんを描けたか」が出る

シリアルの命令:

| 命令 | 意味 |
|---|---|
| `i` | 名前の表示 (2 の画面) にして止める |
| `b` | 塗りつぶしの試験に戻る |
| `f 20` | SPI のクロックを 20MHz にする (80、40、27、20、16、10 から選ぶ)。保存して再起動する。既定は 40MHz |

## 確かめること

- 名前の表示で、6 枚とも正しい名前と色が出るか。名前が違う画面に出たら、CS の配線か、アドレスの選び方の誤り。赤のはずが水色などになったら、色の反転の設定 (`invert`) か、色の並び (`rgb_order`) の誤り
- 塗りつぶしの試験で、画面に乱れ (縞、ずれ、ほかの画面の内容) が出ないか
- 何回/秒出るか。40MHz で約 7 回/秒が計算上の値 (240 x 240 x 2 バイト x 6 枚を、40MHz で送る)
- 10 分ほど回したあとの、XIAO のレギュレーターの温度 (指で触れられないほど熱くないか)
- Dupont の 23cm のケーブルは、基板で使う長さより長い。40MHz で乱れたら、20MHz でも試して、両方の結果を残す
