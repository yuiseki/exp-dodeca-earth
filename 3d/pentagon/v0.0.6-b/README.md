# v0.0.6-b

`../v0.0.6/build.py b` が作る。条件は `../constrains.md` の「丸い部分だけを五角形に収める」計算 (`simulate/module_fit/round_contained.py`) で、北極の出っ張りもはみ出してよいとした組。

| 項目 | 値 |
|---|---|
| 辺 | 28.5625 mm (v0.0.5 は 30 mm) |
| 画面の高さ | いまと同じ (基板の裏が板の外側の面に乗る) |
| 側面の画面の出っ張り | 赤道の側 (お椀の縁の頂点)。v0.0.5 から 180 度回す |
| 北極の画面の出っ張り | 五角形の頂点。v0.0.5 から 36 度回す |
| 画面の位置 | 側面は面の中心から出っ張りの向きに -0.5 mm、北極は中心 |
| コネクタの穴 | 出っ張りの反対側 (側面では極の側) |
| 磁石 | 頂点から 4.0 mm (v0.0.5 は 5.0 mm)。角の磁石のボスが取り付け穴にかかるので、穴をボスごと空け直した |

ファイル:

- `lcd_cup.stl` / `.step`: お椀 (底 1 枚と側面 5 枚をつないだもの)。同じものを 2 個刷る
- `lcd_pentagon_plate_side.*`: 側面の板 (磁石のボスつき)
- `lcd_pentagon_plate_pole.*`: 北極 (底と天) の板
- `lcd_pentagon_plate_side_plain.*`: ボスを付ける前の側面の板 (途中のもの)
- `magnets_side.json`: 磁石の穴の位置

画面を付けた組み立ては `simulate/v0.0.6-b/` (`simulate/v0_0_6.py b` が作る): `dodecahedron.3mf` と、上のお椀を 30 mm 浮かせた `dodecahedron_exploded.3mf`、磁石の極の表 `magnets.csv`。そこで確かめたこと:

- 板どうし、画面どうし、板と画面 (隣の板とも)、磁石と他の部品の重なりは、どれも 0 mm³
- 板の角は正十二面体の頂点に重なる (ずれ 1e-11 mm 以下)。隣の板とは、辺ごとに 60 mm² 以上の面で接する
- 磁石 20 組が向かい合い、1 つの極の表で上下のお椀に使える。正しい向きの +20 に対し、間違った 72 度の回し方では -4 (反発)

まだ確かめていないこと:

- 中の空間。辺が小さくなったぶん、rev E の基板を置ける深さが浅くなる (見積もりでは、いまより約 2 mm)。XIAO と Sense が収まるか
- 底の画面の PH2.0 プラグの高さ
- 画面の絵の向き: 側面は 180 度、北極は 36 度回して描く (ファームか `make_earth_faces.py`)
